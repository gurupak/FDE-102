# Command cheat sheet

| Command | Description |
| --- | --- |
| `gh run list` | List recent workflow runs |
| `gh run watch` | Follow a run live |
| `gh run view --log` | Full log of a run |
| `gh pr checks --watch` | Watch checks on a PR |
| `gh pr merge --squash` | Merge a PR as one commit |
| `git check-ignore -v` | Show which .gitignore line ignores a file |
